# フォントについて
フォント名と実際に使用しているフォント名や公式へのリンクを記載します。

* 各フォントリソースは `resource/fonts/<fontname>` にフォント利用許諾が確認できる資料と共に保管して下さい。
* プロポーショナルと等幅は別フォントとして扱います。例: apricot, apricot-mono

## 楷書体・毛筆体・行書体・手書き風
### vanilike-book
恐らく元のフォントはダイナフォントのDFP魏碑体(W7)と[Cyrodiil](https://www.dafont.com/cyrodiil.font)を組み合わせたもの。

* 基本フォント: [SkyrimSE v1.6.1170]() ※22_Skyrim_JP_BookFont_0805を使用。
* 補間フォント: [Tフォント](https://charcenter.tron.org/tfont/) ※楷書体を使用。

### tfont-kaisho

* 基本フォント: [Tフォント](https://charcenter.tron.org/tfont/) ※楷書体を使用。
* 補間フォント: 

### vanilike-handwrite
恐らく元のフォントはダイナフォントのDFP行書体(W5)と何らかの英字フォントを組み合わせたもの。

* 基本フォント: [SkyrimSE v1.6.1170]() ※5_Skyrim_JP_HandWriteFont_0805を使用。
* 補間フォント: [英椎行書](https://www.ac-font.com/jp/detail_jb_006.php)


### lore-friendly-everywhere
恐らく元のフォントはダイナフォントの隷書体系。元MODはeverywhereとbookに採用されている。

* 基本フォント: [Lore-friendly fonts - font_jp_skyrim v1.0](https://www.nexusmods.com/skyrim/mods/46205) ※Skyrim_nを使用。
