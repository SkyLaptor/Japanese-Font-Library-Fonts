# 技術パッチ作成ガイド

Skyrim本体やModのUIバグを修正するための技術的な手順です。

## バニラUIの修正
### 本UIの内蔵フォントバグ (`book.swf`)
英語版の `interface/book.swf` にはフォントファイルが内蔵されており、日本語の表示を妨げることがあります。FFDecを使用して、内蔵されているフォントリソースを削除してください。

### レベルアップメニュー (`levelupmenu.swf`)
日本語版ではフォントマップの指定ミスがあるため、英語版の `levelupmenu.swf` をベースに使用します。ただし、表示サイズが大きすぎるため、FFDecで `ymin` を調整し、HTMLレンダリングを有効にしてフォントサイズを制限する加工が必要です。

## SkyUIパッチ
### MCM専用フォントマップ
設定メニュー(MCM)で文字がはみ出る問題を解決するため、`Interface/skyui/configpanel.swf` を書き換え、MCM専用のフォントマップ（長体フォントなど）を参照するように変更します。
FFDecでフォントマップ指定箇所を検索し、適切な識別子に置換してください。
