# ユーザーガイド

このディレクトリには、ツールの使い方やレシピの書き方などのユーザー向けドキュメントを配置します。

## 詳細準備
### 【オプション】基準フォントの準備（ゲームデフォルトの日本語フォント）

基準フォントとしてゲームデフォルトのフォントを使用する場合の手順です。

1. 最新版のSkyrimSE 英語版をインストールします。（v1.6.1170以降には日本語フォントが含まれています）。

2. `Skyrim\Data\Skyrim - Interface.bsa` をBSA Browserで開きます。

3. `interface\fonts_ja.swf` を取り出し、FFDecで開きます。

4. 左ツリーの **[フォント]** から、任意のフォントを右クリックして **[エクスポート]** します。
   * **Every**: `1_Skyrim_JP_EveryFont_0805`
   * **Book**: `22_Skyrim_JP_BookFont_0805`
   * **Handwrite**: `5_Skyrim_JP_HandWriteFont_0805`

5. このツールを起動し、**[個別:フォント加工]** タブで、空白グリフ除去を有効(デフォルト)にして、他は何も変更せずに出力します。
   * 出力先: `contents\skyrim\1_Skyrim_JP_EveryFont_0805.ttf` / `22_Skyrim_JP_BookFont_0805.ttf` / `5_Skyrim_JP_HandWriteFont_0805.ttf`


## ワンポイントアドバイス
### フォント幅変更時に、異様に細くなる文字がある
対象の文字が参照文字である可能性が高いです。FontForgeなどで参照解除を行ってください。

### フォント太さ変更時に、逆に細くなったり太くなったりする文字がある
アウトラインの向きが逆になっている可能性が高いです。FontForgeなどでアウトラインの向きを修正してください。

### 英字フォント＋日本語フォントをマージする際に、英字側が極端に幅が狭い場合

普通に行うと、英字側がW70,W50版でさらに狭くなってしまいます。（幅は日本語フォントの幅を基準に縮小されるため）
たとえば `Futura Condensed` + `Noto-Sans` の組み合わせの場合、`Futura Condensed` がもともと幅が狭いため、W70やW50では英字部分がとてつもなく細くなります。

事前に英字側を 横幅220% `((100-70)*4+100)` や 横幅300% `((100-50)*4+100)` のサイズを用意しておき、それと結合した上でマージすれば、大抵の場合はそこまで違和感なく合うはずです。必要に応じて係数部分(`*4`)を調整して下さい。

英字側のフォントの横幅違いを作成する場合は、**[単体フォント加工]** 機能にて、横幅のみ設定しサブセットなども除いて処理を行えば作成できます。

### 基準が傾いているフォントの場合
[Fontforge](https://fontforge.org/en-US/) を用いて、フォントを傾けて下さい。

fontforgeに対象のフォントを読み込ませ、全グリフを選択(`Ctrl+A`)した後に右クリック、変形→傾きで設定可能です。
